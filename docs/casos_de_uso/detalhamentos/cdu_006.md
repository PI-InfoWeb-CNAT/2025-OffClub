## 1. Resumo

O usuário assinante acessa e visualiza seu histórico de consumo na plataforma: poderá visualizar o status das ofertas resgatadas por ele (se estão ativas, se foram utilizadas ou expiradas), a empresa que disponibilizou a oferta e período de vigência da oferta.

## 2. Atores

- Principal: Assinante

## 3. Pré-condições

- Assinante devidamente cadastrado e com assinatura ativa
- Ofertas devidamente registradas e atribuídas ao resgate pelo assinante

## 4. Pós-condições

- Exibição devida do histórico de consumo do assinante ao decorrer do seu uso da plataforma.

## 5. Fluxos de Eventos

### 5.1 Fluxo Principal

| Ator | Sistema |
| :--: | :-----: |
| 0. O assinante clica no botão "Visualizar histórico" na aba de perfil | - |
| - | 1. O sistema exibe todas as ofertas resgatadas pelo assinante durante todo o seu período de uso da plataforma |

### 5.2 Fluxos de Exceção

#### 5.2.1 sessão expirada

| Ator | Sistema |
| :--: | :-----: |
| - | 1.1. O sistema exibe uma mensagem de que a sessão expirou |
|| (retorna ao login) |

## 5.3 Fluxos Alternativos

#### 5.3.1 Nenhum cupom encontrado

| Ator | Sistema |
| :--: | :-----: |
| - | 1.1. O sistema exibe a mensagem que nenhuma oferta foi encontrada |
