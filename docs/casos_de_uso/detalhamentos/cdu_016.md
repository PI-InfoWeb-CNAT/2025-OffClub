## 1. Resumo

O cliente assinante pode pesquisar e filtrar pelas ofertas disponíveis ao plano de assinatura.

## 2. Atores

- Principal: Assinante

## 3. Pré-condições

- Assinatura ativa
- Ofertas devidamente registradas

## 4. Pós-condições

- Exibição das ofertas que estão de acordo com os filtros selecionados pelo assinante

## 5. Fluxos de Eventos

### 5.1 Fluxo Principal

| Ator | Sistema |
| :--: | :-----: |
| 0. O assinante entra no dashboard de ofertas | - |
| - | 1. O sistema retorna os dados da página de ofertas |
| 2. O assinante desce a página até a parte de pesquisa por ofertas, seleciona os filtros e realiza a pesquisa | - |
| - | 3. O sistema realiza a busca e renderiza os cards de cada oferta resultante da pesquisa |

### 5.2 Fluxos de Exceção

## 5.3 Fluxos Alternativos

### 5.3.1 Nenhum resultado à pesquisa

| Ator | Sistema |
| :--: | :-----: |
| 2.1 O visitante seleciona os filtros e realiza a pesquisa | - |
| - | 3.1 O sistema não encontra ofertas correspondentes e renderiza uma mensagem de que nenhum resultado foi encontrado no lugar dos cards |
