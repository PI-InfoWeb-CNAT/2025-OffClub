## 1. Resumo

O usuário empresa pode conferir as avaliações submetidas pelos assinantes às suas ofertas.

## 2. Atores

- Principal: Empresa

## 3. Pré-condições

- Empresa com cadastro aprovado
- Oferta(s) devidamente cadastrada(s)

## 4. Pós-condições

## 5. Fluxos de Eventos

### 5.1 Fluxo Principal

| Ator | Sistema |
| --- | --- |
| 0.  Na página de gestão de ofertas, o usuário empresa clica para consultar as avaliações de uma oferta específica.  | - |
| - | 1.  O sistema o direciona a uma página contendo todas as avaliações submetidas.  |

### 5.2 Fluxos de Exceção

#### 5.2.1 Oferta não encontrada

| Ator | Sistema |
| --- | --- |
| - | 1.1 O sistema exibe uma mensagem indicando que a oferta não foi encontrada.  |
|  | (retorna ao passo 0) |

## 5.3 Fluxos Alternativos

### 5.3.1 Nenhuma avaliação submetida

| Ator | Sistema |
| :--: | :-----: |
| 1.2. O sistema o direciona a uma página contendo uma mensagem informando que nenhuma avaliação foi submetida à oferta | - |
| - | (retorna ao passo 0) ||
