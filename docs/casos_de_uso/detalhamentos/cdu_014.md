## 1. Resumo

O usuário assinante pode assinar um dado plano.

## 2. Atores

- Principal: Assinante

## 3. Pré-condições

- Forma de pagamento válida
- Assinante com nenhuma assinatura vigente

## 4. Pós-condições

- Dados de assinatura devidamente persistidos

## 5. Fluxos de Eventos

### 5.1 Fluxo Principal

| Ator | Sistema |
| --- | --- |
| 0.  Na página inicial, o usuário empresa clica no botão de "escolher plano" no card do plano desejado.  | - |
| - | 1.  O sistema o direciona ao gateway de pagamento externo.  |
| 2.  O usuário efetiva o pagamento no gateway integrado.  | - |
| - | 3.  O sistema recebe a confirmação de pagamento do gateway externo e persiste os dados da assinatura, ativando-a.  |

### 5.2 Fluxos de Exceção

#### 5.2.1 Plano não encontrado

| Ator | Sistema |
| --- | --- |
| - | 1.1. O sistema exibe uma mensagem indicando que o plano não foi encontrado.  |
|  | (retorna ao passo 0) |

#### 5.2.2 Sessão expirada

| Ator | Sistema |
| --- | --- |
| - | 1.2. O encaminha a página de login indicando que a sessão expirou.  |

## 5.3 Fluxos Alternativos

### 5.3.1 Pagamento cancelado

| Ator | Sistema |
| :--: | :-----: |
| 3.3. O sistema não recebe a confirmação do gateway e cancela a operação. | - |
| - | (retorna ao passo 0) ||
