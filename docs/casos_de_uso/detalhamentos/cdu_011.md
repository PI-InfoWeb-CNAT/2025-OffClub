## 1. Resumo

O usuário assinante acessa e visualiza seu histórico de cupons emitidos na plataforma, podendo visualizar o status dos cupons por ele emitidos (se estão ativos, se foram utilizados ou expirados), a empresa que disponibilizou a oferta e período de vigência da oferta.

## 2. Atores

- Principal: Assinante

## 3. Pré-condições

- Assinante devidamente cadastrado e com assinatura ativa
- Cupons devidamente registrados cujo emissor atribuído seja o assinante

## 4. Pós-condições

- Exibição devida do histórico de consumo do assinante ao decorrer do seu uso da plataforma.

## 5. Fluxos de Eventos

### 5.1 Fluxo Principal

| Ator | Sistema |
| :--: | :-----: |
| 0. O assinante clica no botão "Visualizar histórico" na aba de perfil | - |
| - | 1. O sistema exibe todas os cupons emitidos pelo assinante durante todo o seu período de uso da plataforma |

### 5.2 Fluxos de Exceção

#### 5.2.1 sessão expirada

| Ator | Sistema |
| :--: | :-----: |
| - | 1.1. O sistema exibe uma mensagem de que a sessão expirou |
|| (retorna ao login) |

## 5.3 Fluxos Alternativos

#### 5.3.1 Nenhum cupom encontrado

| Ator | Sistema |
| :--: | :-----: |
| - | 1.1. O sistema exibe a mensagem que nenhum cupom foi encontrado |
