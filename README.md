# OffClub - Projeto Integrador InfoWeb - IFRN

Projeto elaborado e implementado por alunos do terceiro ano do Curso Técnico de Nível Médio Integrado em Informática para Internet do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Norte Campus Natal-Central para a disciplina de "Desenvolvimento de Projeto Integrador" no período letivo referente ao ano de 2025.

O projeto visa desenvolver uma plataforma de um clube de descontos, buscando benefício mútuo aos clientes assinantes e às empresas parceiras, favorecendo o comércio local.

Todo material está publicado sob licença [GPL-3.0](https://www.gnu.org/licenses/quick-guide-gplv3.pt-br.html).
